## What this covers

Local orchestration with .NET Aspire, health checks and graceful shutdown, running on Kubernetes, and hosting on AWS: ECS, EKS and Lambda.

Aspire's documentation has moved off Microsoft Learn and now lives at [aspire.dev](https://aspire.dev/). On the AWS side, start with the [AWS SDK for .NET](https://docs.aws.amazon.com/sdk-for-net/) and [building Lambda functions with C#](https://docs.aws.amazon.com/lambda/latest/dg/lambda-csharp.html).
