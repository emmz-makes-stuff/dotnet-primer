## Who this is for

You know C# and .NET Framework well. You've shipped and maintained a large .NET 3.5 codebase for years. Modern .NET keeps the language and much of the base library, but the platform, the tooling and the idioms around them have changed a lot. This primer gets you productive on them quickly.

## How it's organised

- **The learning path** uses **ASP.NET Core** as its main thread. It introduces everything else along the way, starting with configuration, dependency injection and middleware. Follow it in order, using the **Next** links at the bottom of each page.
- **C# language** catches you up on everything since C# 3.0, as a separate section.
- **Coming from .NET 3.5** maps the habits you already have to their modern equivalents.
- **Cheatsheets** are one-page references to keep open while you work.
- **Exercises** in the [GitHub repo](https://github.com/emmz-makes-stuff/dotnet-primer/tree/main/samples) let you practise. You clone them, run them locally, and use their tests to check your work.

Every page links to the official docs on Microsoft Learn. If you spot a mistake or something missing, use **Report a problem** at the bottom of the page.
