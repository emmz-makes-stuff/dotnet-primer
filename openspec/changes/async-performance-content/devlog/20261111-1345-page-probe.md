## Starvation: the same 200 concurrent requests, each a 500 ms wait

| Endpoint | Total | p50 | p99 | `dotnet.thread_pool.thread.count` max | `dotnet.thread_pool.queue.length` max |
| --- | --- | --- | --- | --- | --- |
| `/blocking` (`Task.Delay(500).Wait()`) | 28 145 ms | 27 885 ms | 27 906 ms | 29 | 168 |

- **Command:** `dotnet-counters collect -p <pid> --counters System.Runtime --format csv -o … --duration

## `async void`: crashes the process

A console app calls `async void SendReceipt(42)`, which throws after an `await`. Output:

```text
Receipt sent, carrying on.
Unhandled exception. System.InvalidOperationException: The mail server refused the receipt for order 42.
```

Then a stack trace. The exit code is **134** (SIGABRT), and "Still running." never prints.

## Disconnect, `Task.WhenAll`, `HybridCache`, output caching

- **Client disconnect:** a `fetch` aborted after 300 ms, against `await Task.Delay(10_000,
  cancellationToken)`. The client gets `AbortError`. The server catches
  `System.Threading.Tasks.TaskCanceledException: A task was canceled.`
- **Two 500 ms awaits:** **1002 ms** one after another, and **501 ms** with `Task.WhenAll`.
- **`HybridCache`** (`AddHybridCache()`, in-memory only, `GetOrCreateAsync` with a 200 ms factory,
  a 5-minute `Expiration` and the tag `prices`):
  - 50 concurrent requests for one key: **1** factory call;
  - one more request: still 1;
  - after `RemoveAsync(key)`, one more: 2;
  - after `RemoveByTagAsync("prices")`, one more: 3. **Removal by tag works with the in-memory
    level alone.**
- **Output caching** (`AddOutputCache()`, `UseOutputCache()`,
  `.CacheOutput(p => p.Expire(30 s).Tag("catalogue"))`, and a handler counter in the body):
  - first: `catalogue, built 1 times`, no `Age` header;
  - 1.1 s later: `built 1 times`, with **`Age: 1`**, so the `Age` header is how to tell;
  - with `Authorization: Bearer x`: `built 2 times`, no `Age`. **An authenticated request isn't
    served from the cache,** as D6 said;
  - after `IOutputCacheStore.EvictByTagAsync("catalogue")`: `built 3 times`.

## BenchmarkDotNet against the samples' analyzers

With the samples' `Directory.Build.props` (warnings as errors, latest-recommended, code style in
build) and one benchmark class:
- **CA1822** on each `[Benchmark]` method that reads only a `const`;

- put the benchmarks in a namespace;

  anyway, so the JIT can't fold a constant input away, and it clears CA1822 without a suppression.

Suppress CA1822 only if that fails.
