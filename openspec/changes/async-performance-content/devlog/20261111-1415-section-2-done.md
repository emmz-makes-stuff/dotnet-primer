## Gotchas this section (all in design D3's "Revised in §2", or in the code's comments)

- **`TestServer` runs a handler on the caller's thread until its first `await`.** Against the
  Starter's blocking sync handler, the cancellation test hung for good: `PostAsJsonAsync` never
  returned, so the token couldn't end it. Now it sends from `Task.Run`, and awaits `placing` only
  after `ReserveCancelled`. The fake's `Dispose` frees the held call, so the app can stop.
- **In the Testing environment, `TestServer` rethrows the app's unhandled exception to the client**
  (the probe's 500 was the Development exception page). The quote test catches the fake's
  `TimeoutException`, and fails with the TODO 4 hint.
- **`WebApplicationFactory.DisposeAsync` calls `Dispose(true)` again**, so `FakeWarehouse.Dispose`
  is idempotent (an `Interlocked` flag).
- **The MTP `--timeout` didn't stop the hang;** `timeout 60 dotnet test … -- --filter-method <name>`
  per test found it.
- **`dotnet format` (IDE1006) wants a `_` on private static readonly fields** (`_latency`,
  `_patience`, `_awaiters`). `make samples-build` doesn't catch it; `samples-format` does.
- CA1031 isn't on under `latest-recommended`, so the worker's `catch (Exception)` has no pragma.
