## Decision: build the page from compiled files

The page's C# blocks are not hand-copied. The page was generated from a template
(`scratchpad/di-page.tmpl.md`), with `@@name@@` lines replaced by compiled fragments
(`scratchpad/frag/*`, extracted from `snip/cases/di-*.cs`). After Prettier ran, a substring check
confirmed that every fragment still appears verbatim on the page. I'll reuse this for Middleware (§7).
- **Gotcha:** the perl placeholder regex `\S+` swallowed the trailing `@` and aborted mid-write. That
  truncated the page, but the exercise section had been saved first, so nothing was lost. The fix is
  the pattern `([^@\s]+)`.
