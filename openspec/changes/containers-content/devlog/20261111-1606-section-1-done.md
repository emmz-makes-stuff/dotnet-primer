## Design and plan updates (from what the probes found)

Nothing in the specs changed. These updates are in `design.md`, `proposal.md` and `tasks.md`:
- **D5:** the non-root check lists the running processes through the Docker API (`docker top`).
  It doesn't read `/proc/1/status` through the file copy, which returns an empty file. D5's
  `docker inspect` fallback, and the stop it guarded, aren't needed: the check still looks at
  what runs.
- **D4 TODO 3:** the fix is `ContainerFamily=noble-chiseled` **plus** `InvariantGlobalization=true`.
  Without it, the SDK quietly picks `-noble-chiseled-extra`.
- **D1:** no `docker debug` (Docker Desktop only). Inspect with `docker cp`, `docker top` and a
  `--pid=container:` sidecar. SqlClient needs `-extra`.
- **D2:** the probe machine runs **OrbStack**, not Rancher Desktop. **D8:** the Trivy command is
  pinned, and the page refers to the Docker page for Rancher's socket instead of stating an
  unmeasured mount.
- **D7, proposal, tasks:** `registry:3`, not `registry:2`.

## Things a cold session needs to know

- Scratch probes outside the repo **must copy `global.json` in**, or they build on the 11.0 RC.
- `localhost:8080` on this Mac hits an unrelated Vite dev server on `::1`. Use `127.0.0.1`, or a
  different host port. Don't kill it.
- Port 5000 is ControlCenter's. The registry uses 5001.
- The `rm -rf "$VAR"` safety check blocks the whole command. Don't put removals in work commands.
- `dotnet test` (MTP) hides test output: run the test exe with `-showliveoutput`.
- `make samples-test` baseline: **29 s** (warm), before exercise 12.
