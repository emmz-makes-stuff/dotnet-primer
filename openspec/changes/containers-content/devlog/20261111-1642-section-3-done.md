## Gotchas

- context-mode's hook blocks `curl`, **and any inline HTTP in a Bash command** (`node -e fetch`).
  Run Docker in Bash, then call the endpoint with `ctx_execute`'s `fetch`. It reaches
  `127.0.0.1:8080`.
- `localhost:8080` still reaches the unrelated `::1` Vite server, so use `127.0.0.1`.
- Docker 29.8's `docker image ls` column is `DISK USAGE`, not `SIZE`. The page says only
  "`docker image ls`'s".
