## Deviations from the design (decided, not product questions)

- **Docker's install page isn't in `learn:`.** The content schema rejects non-Learn URLs ("Microsoft
  Learn links must start with https://learn.microsoft.com/"), and the build failed with it. It's
  linked in the body instead, and design D7 is updated.
- **Colima gets a concrete fix, not a pointer to the Testing pages.** Those pages are still stubs,
  so the page shows `export DOCKER_HOST="unix://$HOME/.colima/default/docker.sock"` (Colima FAQ,
  v0.4.0 or later). It doesn't claim this is all Testcontainers needs: Testcontainers with Colima
  also needs a socket override, which belongs on the Testing pages when they are written.

## Gotcha

`npx --prefix site prettier …` run from the repo root fails ("Cannot find package
'prettier-plugin-astro' imported from …/noop.js"). Run `npx prettier` from inside `site/`. In the
last change I piped that command to `/dev/null`, which hid the failure, but `make site-format`
still passed there, so nothing was left unformatted.
