**Decision: `ASTRO_TELEMETRY_DISABLED=1` is set in the `dev`, `build`, `preview` and `lint` scripts.**

- Why: Astro's telemetry writes config under `~/Library/Preferences/astro`. The sandbox denies that,
  so the build crashed in `@astrojs/telemetry` `mkdirSync`. A docs build gate also shouldn't phone
  home.
- Rejected:
  - setting the variable in the Makefile, which would leave CI and direct npm use still reporting;
  - running `astro telemetry disable`, which is per-machine, writes the same blocked path, and doesn't
    help CI.
- Cost: the `VAR=x cmd` syntax isn't Windows-cmd friendly. That's acceptable, because all the targets
  are macOS and Linux.
