  (scratchpad `grpc-page/Server/Snippets.cs`): `0 Warning(s)`, warnings as errors. The only change

- **"From the exercise" blocks match the real files,** line by line in order, ignoring indentation
  (scratchpad `check-snippets.mjs`): the `.proto`, `Grpc.Solution.csproj`, and `PlaceOrder` and
  `TrackOrder` from `Solution/OrdersService.cs`. The `PlaceOrder` block ends with the elision
  `// GetOrder and TrackOrder follow.` and `}`.
- **Run on Kestrel** (scratchpad `grpc-page/`, server on `http://localhost:5287` with `Http2`, and a
  console client). The page quotes these results:
  - `NotFound`, detail "There's no order 7.";
  - `InvalidArgument` with `BadRequest` read back on the client: "customer_email: A customer email is
    required.";
  - an unhandled exception: `Unknown`, "Exception was thrown by handler." in Production; in
    Development, with `EnableDetailedErrors`, "… InvalidOperationException: Something secret
    broke.";
  - a server stream, a client stream (3 imported), and a bidirectional stream all worked;
  - a 500 ms deadline on a stream with 1 s between messages: `DeadlineExceeded`, empty detail;
  - `EnableCallContextPropagation`: with a 5 s deadline on `PlaceOrder`, the onward `Reserve` call saw
    `4.999330s` left;
  - health: `Serving`, then `NotServing` straight after a check started failing (no cache; still
    `NotServing` 6 s later);
  - the HTTP/1.1 error text is from the 1.1 probe;
  - **new:** a deadline from `DateTime.Now` or with `DateTimeKind.Unspecified` throws
    `InvalidOperationException: Deadline must have a kind DateTimeKind.Utc or be equal to
    DateTime.MaxValue or DateTime.MinValue.` before sending. That's now a Pitfall.
- **Links:** every URL on both pages resolves (Learn 302→200). `protobuf#decimals` and the
  Kubernetes `#define-a-grpc-liveness-probe` anchors exist (Kubernetes writes its ids unquoted). The
  exercise's GitHub tree link is 404 until `08-grpc` is on `main`, as 07's was.

  `prettier-plugin-astro`.
- **A first `make gates` failed `SAMPLES_BUILD`** with CS2012 "Access to the path … is denied" on

  fixed it (CLAUDE.md's note on sandboxed build nodes).
- **Devlog file names:** the two §2 notes were named with guessed times (1640, 1655) that sorted
  after this one. They're renamed to 1600 and 1605, in the order they were written. Use `date` for
  every note's name.
