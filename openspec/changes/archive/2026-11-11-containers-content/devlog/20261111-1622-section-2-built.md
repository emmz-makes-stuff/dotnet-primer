## Found and fixed while verifying

- **With an unreachable `DOCKER_HOST`, the failure blamed TODO 3.** Testcontainers falls back to
  other endpoints (OrbStack's socket), so its `Build()` and ping succeeded, while `dotnet publish`
  (the `docker` CLI) failed. Now `docker info` runs first, and the message says
  `` `docker info` failed: … Exercise 12's tests need a running Docker engine … `` with the Docker
  page link. Verified with `DOCKER_HOST=unix:///tmp/no-such-docker.sock`. The no-`docker`-on-PATH
  branch (a `Win32Exception`) is untested, because stripping PATH broke the `dotnet` launch itself.
- The message named the folder ("Solution"), not the project. `ProjectName` now comes from the
  `.csproj`.
- Analyzers: CA1873 (the options lookup inside the log call, moved to a local), CA1822
  (`NewName` is now static), and **IDE1006 on a private `const`**: the repo's rule covers private
  constants too (`_dockerNeeded`, like exercise 10's `_letThrough`).
