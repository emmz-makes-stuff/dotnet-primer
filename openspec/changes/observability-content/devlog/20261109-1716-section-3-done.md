## Gotchas

- **context-mode blocks inline HTTP in Bash** (`node -e 'fetch…'` too). Put the fetching in a
  scratchpad `.mjs` file (`logsnip/run.mjs`), or use `ctx_execute`.
- **`dotnet run` ignores SIGINT from a node `spawn`:** the app outlives it, and the Bash call hangs.
  Spawn the built binary (`bin/Debug/net10.0/LogSnip`) with `ASPNETCORE_URLS` instead.
- The old link checker lives in an archived session's scratchpad. The inline `ctx_execute` version
  used here checks all `https://` links, not only Learn.
