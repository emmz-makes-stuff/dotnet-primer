## Design changes in this section

These are all details inside the existing decisions. No spec changed.
- **D3:** the drain delay (Emmz's answer A), and that on ECS the ALB deregisters the task before
  SIGTERM, so there the delay is a safety margin. It matters most on Kubernetes.

## For the next sections (things the repo doesn't record elsewhere)

- **2.3 test cost:** each shutdown test takes about the order's length (5 s in the probe). Disposing
  `WebApplicationFactory` after the host has stopped runs `StoppingAsync` again, so the drain delay
  is paid twice per test. Keep the Solution's delay short, or let the tests set it short through
  configuration. Decide while writing 2.2 and 2.3, and record how long `make samples-test` takes,
  before and after.
- **Port 5000:** never use `UseKestrel(0)`. It listened on `localhost:5000`, where macOS
  ControlCenter answers `403` once Kestrel has gone.
- **§3 numbers, all measured or from the docs:**
  - `ShutdownTimeout` defaults to 30 s, and `docker stop` to 10 s, then `137`;
  - `--init` makes no difference to a stop;
  - a short `ShutdownTimeout` loses the order, and the exit code is still 0;
  - ECS `stopTimeout` defaults to 30 s, with a maximum of 120 s on Fargate;
  - the ALB's deregistration delay defaults to 300 s;
  - the ALB health check defaults to path `/`, 30 s interval, 5 s timeout, healthy threshold 5,
    unhealthy threshold 2, matcher `200`;
  - Lambda's timeout is 900 s, and there's a `dotnet10` runtime;
  - EKS costs $0.10 per cluster per hour ($0.60 in extended support).
- **§3 Aspire:**
  - Aspire CLI 13.6.0 with SDK 13.6.5, and a file-based `apphost.cs`;
  - `ConnectionStrings__Orders` comes from `AddDatabase("Orders")`, so the Compose API ran
    unchanged;
  - SQL Server is `mssql/server:2022-latest` (`amd64`, under emulation);
  - the dashboard signs in with `/login?t=<token>`;
  - ServiceDefaults maps `/health` and `/alive` only in Development (`404` in Production);
  - a hand-made project needs a `launchSettings.json` endpoint;
  - a taken port fails silently.
- **§3 task definition:** in `1908`, key-checked. Its `CMD-SHELL curl` health check is the
  Pitfall's example, so decide in 3.2 whether the page's main block keeps it.
- The scratch projects are in the session scratchpad (`hs/`, `asp/`, `aws/`) and are gone after a
  clear. Every snippet and output the page needs is in the notes above.
