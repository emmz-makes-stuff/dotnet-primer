## Emmz's answer: how the C# 3 examples are verified

D11 says every block is compiled "with the repo's `.editorconfig` and warnings as errors", but the
samples' `.editorconfig` makes a block namespace an error, which genuine C# 3 code uses. Asked;
Emmz's answer (2026-11-11): **compile them as real C# 3.** C# 3 blocks are built with
`LangVersion` 3, `Nullable` and `ImplicitUsings` off, `TreatWarningsAsErrors` and
`AnalysisLevel=latest-recommended`, but `EnforceCodeStyleInBuild=false`. Modern blocks get the
samples' settings in full. The page's intro paragraph says so.
