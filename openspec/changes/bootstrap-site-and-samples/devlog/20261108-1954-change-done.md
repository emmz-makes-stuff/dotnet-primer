### Drift from `design.md`

All of it is deliberate, and each item is recorded in its section note. `design.md` still describes
the original plan:

- **D4:** the code uses `z.url({ protocol, hostname })`, not `z.string().url().startsWith(...)`. The
  old form is deprecated in Zod 4, and it let lookalike hosts through (§3).
- **D5:** the `Footer` fallback wasn't needed. `EditLink` renders on the splash page (§3).
- **D1/D9:** the project files are named `Configuration.{Starter,Solution}[.Tests].csproj`. The folders
  match D1 (§7).
- **D10:** `concurrency.group` is `pages-${{ github.ref }}`, not `pages` (§8).
- **D2/D8:** `ASTRO_TELEMETRY_DISABLED=1` was added to the astro scripts (§2).

### Nits, not fixed

- `EXPECTED_SLUGS` in the test repeats the sidebar's list, so adding a page means editing both
  places. This is a deliberate independent oracle, but the test could derive the list from
  `astro.config.mjs` instead.
- The scripts use `VAR=x cmd` syntax, so they won't work in the Windows cmd shell. That's acceptable,
  because everything runs on macOS or Linux.
